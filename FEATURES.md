## 🚀 How to Use New Features

### Creating a Receipt with Status
1. Click "Login" → "Add New" in Receipt List
2. Fill in receipt details
3. Select a **Status** from the dropdown (Draft, Pending, Paid, Cancelled)
4. Add items with **Categories**
5. Click "Save"

### Searching and Filtering
1. Open Receipt List
2. Type in the **Search Bar** to find receipts by number or name
3. Use the **Status Dropdown** to filter by status
4. Both filters work together for precise results

### Exporting Data
1. Open Receipt List
2. Apply any filters you want
3. Click **"Export CSV"** button
4. File downloads automatically with current date

### Using Dark Mode
1. Click the **Sun/Moon icon** in the navbar
2. Background switches between light and dark
3. Toggle anytime for your preference
