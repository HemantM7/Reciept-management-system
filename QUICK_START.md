# ⚡ Quick Start Guide

## 🚀 Get Started in 3 Steps

### 1️⃣ Install
```bash
npm install
```

### 2️⃣ Run
```bash
npm run dev
```

### 3️⃣ Open
Navigate to `http://localhost:5173`

---

## 🎯 Key Features at a Glance

### 📊 Dashboard
- View real-time statistics
- 4 stat cards: Receipts, Revenue, Items, Average
- Interactive charts

### 🧾 Receipt Management
- Create/Edit/Delete receipts
- Track status: Draft → Pending → Paid
- Add items with categories
- Auto-calculate totals

### 🔍 Search & Filter
- Search by receipt # or name
- Filter by status
- Real-time results

### 📤 Export
- Export to CSV
- Print receipts
- One-click download

## 📝 Quick Actions

### Create a Receipt
1. Click "Login"
2. Click "Add New"
3. Fill details
4. Add items
5. Click "Save"

### Search Receipts
1. Open Receipt List
2. Type in search bar
3. Results appear instantly

### Export Data
1. Open Receipt List
2. Apply filters (optional)
3. Click "Export CSV"

### Toggle Dark Mode
Click sun/moon icon in navbar

## 🎨 Color Codes

- **Draft** = Blue
- **Pending** = Yellow
- **Paid** = Green
- **Cancelled** = Red
